# social-review-deck

Attach your Meta post exports (one per year) and your logo, and get an editable PowerPoint social media review: year over year, top posts collage, best post types, hashtags, partners and timing, themed from the logo's colors on the same photo backgrounds as race-review-deck.

See the repository README for install and usage. The slide list lives in `skills/social-review-deck/slides/deck.json`. See `skills/social-review-deck/references/slide-library.md` to change it.
