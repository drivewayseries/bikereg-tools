# race-review-deck

Attach your BikeReg registration CSVs (one per year) and your race logo, and get an editable PowerPoint post-race review: themed from the logo's colors, on the preset photo backgrounds, with a takeaway headline on every slide.

See the repository README for install and usage. The slide list and photos live in `skills/race-review-deck/slides/` and are fetched from GitHub at run time — see `skills/race-review-deck/references/slide-library.md` to change them.
